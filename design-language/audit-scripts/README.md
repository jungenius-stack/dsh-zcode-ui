# audit-scripts — 双端 CDP 探针库

| 前缀 | 对端 | 用途 |
|---|---|---|
| `zc-*` | ZCode (9224) | 几何/hover 波/点击滚动/浮层基准测量 |
| `v5-*` `v6*` | DSH (9223) | 点击手感采样、浮层几何、aria/键盘/减动效/窄视口对抗探针 |
| `extract-*` | ZCode (9224) | 设计令牌全量提取（双主题） |
| `tokens-raw-dump.json` | — | 2026-10-26 令牌原始 dump（备份真源） |

注意：脚本里的选择器是 2026-10-26 时点快照（DSH 刻度=data-index、nav=aria-label"轮次导航"），升级后先跑 `zc-measure` 校准。运行前置：两端带调试端口；用后恢复视图（脚本内已含恢复逻辑）。
