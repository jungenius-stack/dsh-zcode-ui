# 03e 顶栏（header）对照矩阵：ZCode × DSH

> ZCode 侧：2026-10-27 CDP 9224 实测（innerWidth 1198，深色）
> DSH 侧：2026-10-27 CDP 9223 实测（innerWidth 1280，深色，`header.ST7X_W_header`）
> **本轮只盘点不修改。**

## 0. 一句话结论

**顶栏高度两侧完全一致（48px），差距集中在「分隔线」与「页签样式」。**
这与 composer 的情况类似：骨架已经对了，缺的是细节层。

## 2. 缺口判定表

| 编号 | 项 | 判定依据（改前 → 改后） | 风险 |
|---|---|---|---|
| **HD1** | 补 1px 底部分隔线 | 顶栏 `border-bottom` 0px → `1px solid` 白 5% alpha（深色）/ 黑 5%（浅色） | 低。纯加边框，但需确认不与宿主已有分隔冲突 |
| **HD2** | 内边距归一 | `10px 28px 10px 20px` → 左右对称 | 中。会影响顶栏内元素位置，需截图复核 |
| **HD3** | 标题字号/字重 | ZCode 实测 **14px/600** → DSH 页签 13px/500，需提到 14px/600 | 低。纯字号字重，不涉布局 |
| ~~HD4~~ | ~~激活页签用令牌~~ | **已撤销**：实测双主题色值自动翻转（深 `#fff` / 浅 `#000`），证明已是令牌驱动 | — |
| **HD5** | 小按钮尺寸/圆角 | 16×20 / 4px → 与 ZCode 的 28×28 / 8px 对齐 | 中。会改变顶栏一排按钮的总宽，可能挤压标题 |

## 3. 值得单独说的两点

### HD4 已撤销（我最初的怀疑被实测否定）

初判时我以为激活页签写死了 `rgb(255,255,255)`，在浅色主题下会不可见——那会是个 P1 可读性 bug。

**实测否定了这个判断**（CDP 切主题后重读计算值）：

```
深色  .ST7X_W_tabActive color = rgb(255, 255, 255)
浅色  .ST7X_W_tabActive color = rgb(0, 0, 0)      ← 自动翻转
```

颜色随主题翻转，说明它本来就是令牌驱动的。**HD4 撤销，不是缺口。**

> 记录这条是因为：如果只按深色快照下结论，就会把一条正确实现误判成 bug 去「修」。
> **双主题实测推翻静态推断**，这个教训值得留着。

### HD5 需要谨慎

顶栏那排小按钮（16×20 / 20×20）比 ZCode 的 28×28 小得多。
放大到 28×28 会让整排宽约 +36px，**可能挤压标题可用宽度**。
建议先只改圆角（4px → 8px，与 composer 的 C9 保持一致），尺寸是否放大单独评估。

## 4. 本轮采样缺口

- **ZCode 无「对话/轨迹/记忆」页签**，H7/H8 属于 DSH 独有结构，没有对照物，只能按 DSH 自身设计语言评判。
- ZCode **浅色主题**未采（其页面当前是深色）。
- **「费用条 / 上下文水位」确认不在 ZCode 顶栏**：实测顶栏右侧只有 Finder/分享/帮助/面板 4 个按钮 +
  1 个打开方式触发器，无费用或水位元素。它们应位于会话区底部或侧栏，
  **本矩阵不覆盖**，需在后续「底部 footer」组件里另行提取。

## 6. 标题栏去重（2026-10-28，commit `98c1311`，用户裁决 A）

**现象**：收起侧栏时，宿主标题栏左侧渲染一组控制钮（`_6Qf49G_leadingSeat`，64px，固定 x≈88）：
「打开侧边栏」+「新建会话」。它与同 x 的面包屑「打开所在项目」**完全重合**，
功能上又与插件自己的入口重复（展开态 header 有「新建任务 / 收缩侧边栏」，收起态窄轨有「展开侧边栏 / 新建任务」）。

**做法**：
```css
html[data-dsh-zcode-skin]:has(.dcu-root) [class*="_leadingSeat"]:has(button[aria-label="打开侧边栏"]){display:none}
```
三条约束：① 只在插件壳在场时隐藏（壳没挂上则保留宿主入口）；② 用 `:has(button[aria-label=打开侧边栏])`
限定座位，不碰标题栏其它区域；③ `display:none` 不卸载 React 组件，宿主快捷键（⌘B/⌘N）路径不受影响。
`aria-label` 随语言变化 → 不匹配时按钮保留（安全降级，宁可重复不丢入口）。

**验证**：展开↔收起往返（收起后从窄轨恢复）；⌘B 实测生效；1280/1024/900 三宽度下按钮均不可见、无重叠；
两状态截图无重复图标。⌘N 未按下（会新建会话），依据是组件仍挂载。
