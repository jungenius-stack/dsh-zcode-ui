# 夜间审计产出目录（2026-10-29 23:00 → 09:00）

每个 worker 产出 `batch-<N>.md`，格式固定：

```
## 批次 N · <模块列表>

### 差异项（有证据）
| 模块 | 项 | 本仓库值 | ZCode 值 | 证据来源 | 建议动作 |
|---|---|---|---|---|---|
（证据来源必须写清：asar 提取的类名/数值、或 CDP 实测、或"无参照，标注未验证"）

### 无参照项（不得猜）
- <项> —— 无 ZCode 例证，跳过
```

**纪律**：只读不写代码；任何数值必须带证据；没有参照的项一律进「无参照」，不许编。
