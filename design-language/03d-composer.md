## 2. 需要决策的两处（不是简单对齐）

### C5 · 边框 vs 内阴影

- ZCode：`1px solid rgba(255,255,255,.15)` —— **外扩边框**，卡片视觉边界清晰。
- DSH：`inset 0 0 1px rgba(255,255,255,.06)` —— **内阴影**，边界极淡、更"无框"。

**为什么不能直接换**：DSH 的内阴影是宿主设计（`--dcu-composer-shadow` 令牌）。
换成边框会让卡片**外扩 2px**，影响与侧栏/内容的间距计算。
→ 建议：**保留内阴影机制，但把 alpha 从 .06 提到 .15**，用同一手法达到可视强度。

### C9 · 按钮圆角混用（最值得修）

DSH 现在四种：`999px`（加号）、`4px`（权限/模型）、`8px`（中间那个）、`999px`（技能）。
ZCode 是**统一 8px**。

这条**风险最低、收益最直接**——纯 `border-radius`，不影响布局。
但要注意：`999px` 的胶囊形态可能是插件刻意做的 ZCode 对齐（早期做过 Kbd/胶囊）。
**动手前要先确认那些 `999px` 是不是有意为之**，别把有意的设计当 bug 改掉。

## 3. 下一步建议顺序（实现轮）

1. **C9 圆角统一**（最低风险，先做）
2. **C5 边框 alpha .06 → .15**（同一手法，不动布局）
3. **C6/C7 内边距与 gap**（会影响卡片高度，需要截图复核）
4. **C8 行高**（影响多行输入时的表现，需测长文本）
5. D-f/g/h/i 等补采后再定

## 5. 发送键固定（2026-10-28，commit `35cab39`）

**现象（用户报告）**：鼠标移到发送按钮上，按钮「往右偏」。

**定位**：按钮本身 28×28 从未移动 —— 动的是它里面的箭头 svg。`CodexSidebar.tsx` 有一条
自 2026-10-13 的「签名细节」：`button[class$=_primary]:hover:not(:disabled) svg{transform:translateX(1px)}`，
设计意图是「悬停时箭头前倾 1px」。在一个每轮都要点一次的按钮上，这 1px 被读成布局不稳。

**做法**：删除该 hover 位移规则与其专用 svg transition；保留按下 `scale(.94)` 回弹；
悬停反馈只剩明度（背景混 88%，原本就有）。

**断言同步**：`design-system.assert.ts` §7 注释块更名「发送键反馈」，并把「悬停位移」
由正向断言改为**反向断言**（`doesNotMatch ... transform:translate`），防止回潮。

**实测（浅色、可发送态）**：idle 与 hover 的箭头 X 均为 1068.25、computed transform 均为 `none`，
位移 0.00px；`lib/client.js` 中 `translateX(1px)` 计数 0。门禁 exit 0。

**回退**：`git reset --hard backup/pre-sendbtn-pin`。

## 6. 宽度手柄的竖线（2026-10-28，commit `646ebc2`）

**现象（用户报告）**：会话区最左/最右各有一条竖细线，鼠标碰到就亮起 —— 用途是拖动改宽，
但它在阅读时会突然出现，被当成内容分隔线。

**来源两处，都是 `::after` 渐变线**：

| # | 归属 | 选择器 | 视觉 | 处理 |
|---|---|---|---|---|
| W1 | 宿主 | `ST7X_W_widthHandle`（10px 通高，`data-side=left/right`） | `::after` 2px 渐变线，hover 时 `opacity 0→1` | `[class*="widthHandle"]::after{display:none}` |
| W2 | 插件 | `[data-dcu-width-handle]`（新建页，32px 热区） | `::after` 100px 渐变线，hover/focus/dragging 亮起 | 删除该 `::after` 及其显影规则 |

**都只删视觉提示**：拖动热区、`col-resize` 光标、拖拽与偏好保存逻辑全部保留。
`widthHandle` 已登记 `UNCHECKED_HOST_ANCHORS`（缺失即不隐藏，安全降级）。

**实测**：会话视图（306 轮）左右手柄 `::after` computed `display:none`（hover 后仍 none，
虽然 opacity 变 1 但不可见），cursor 仍 `col-resize`；新建页插件手柄 `::after content:none`；
合成同类节点验证选择器命中。`verify-hero-width` 的「指示条必须垂直居中」断言改为
「不得再有可见指示条」，拖动用例原样通过。门禁 exit 0。

**回退**：`git reset --hard backup/pre-handle-line`。
